INKBRIEF FOR MAC — README
==========================

INSTALL
1. Unzip this file (double-click InkBrief.zip if it hasn't auto-extracted).
2. Drag InkBrief.app into your Applications folder.
3. Double-click InkBrief.app to launch.

FIRST LAUNCH — "UNIDENTIFIED DEVELOPER" WARNING
Because this app isn't distributed through the Mac App Store or signed with
a paid Apple Developer certificate, macOS Gatekeeper will block it the first
time with a message like "InkBrief can't be opened because it is from an
unidentified developer." This is normal for any app installed outside the
App Store — here's how to open it anyway:
  • Right-click (or Control-click) InkBrief.app → choose "Open" → click
    "Open" again in the dialog that appears.
  • Or: go to System Settings → Privacy & Security, scroll down to the
    Security section, and click "Open Anyway" next to the InkBrief message.
You only need to do this once — after that it opens normally like any
other app.

HOW IT WORKS
InkBrief is a self-contained web app wrapped as a Mac app. When you launch
it, it opens in its own clean window (using Chrome, Edge, or Brave if you
have one installed — no browser tabs or address bar) or in a regular
browser tab if none of those are installed.

For the cleanest, most "native app" feeling window, having Google Chrome
installed is recommended (it's what removes the browser toolbar/tabs).
Without Chrome/Edge/Brave, InkBrief still works perfectly — it just opens
as a normal browser tab in your default browser instead.

YOUR API KEY
InkBrief already comes with an API key built in — there's nothing to
paste in or set up. Just launch the app and start uploading notes.
(This means all InkBrief users share the same key's free-tier quota,
so if you hand this app to a lot of people at once, generation may
occasionally slow down or hit a daily limit.)

REQUIRES INTERNET
InkBrief needs an internet connection to read your notes (it calls
Google's Gemini API) and to load a couple of small support libraries.
It won't work fully offline.
